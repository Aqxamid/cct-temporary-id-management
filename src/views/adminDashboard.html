Import students

Upload a CSV or JSON file containing student reference data.

Required fields studentId, fullName, email Optional fields

dob, course, programStartDate, temporaryExpiryDate, enrollmentStatus, guardianName, address, phone

Supported formats

CSV: the first row must contain headers. Headers are case-insensitive.

CSV sample 
studentId,fullName,email,course,programStartDate,temporaryExpiryDate
2026011827,Juan dela Cruz,juan.delacruz@example.com,BSIT,2026-08-15,2027-03-01

JSON: upload an array of student objects or an object with a students array.

JSON sample 
[
  {
    "studentId": "2026011827",
    "fullName": "Juan dela Cruz",
    "email": "juan.delacruz@example.com",
    "course": "BSIT",
    "programStartDate": "2026-08-15",
    "temporaryExpiryDate": "2027-03-01"
  }
]

Duplicate student IDs are skipped. Imported students remain reference-only until they submit their photo and signature through the student upload portal.
